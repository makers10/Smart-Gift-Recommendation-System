# Gift with Love — Luxury Next.js 15 Discovery Platform

A modern, high-converting luxury gifting discovery platform built with **Next.js 15 (App Router)**, **React 19**, **Tailwind CSS v4 / DaisyUI**, **Framer Motion**, and **21st.dev / ThreeUI** interaction patterns.

---

## 🎨 Visual Identity & Brand Palette

- **Canvas Background**: Warm Cream / Ivory (`#FCF9F2`, `#FFFDF8`)
- **Primary / Accent**: Deep Royal Burgundy / Berry (`#881337`, `#700F2B`, `#4C0519`)
- **Secondary / Badges**: Soft Blush & Champagne (`#FFE4E6`, `#FDF2F8`, `#F5EBE1`)
- **Warm Metallic**: Subtle Golden Amber (`#F59E0B`, `#D97706`)
- **Typography**: Playfair Display (Luxury Editorial Serif) + Plus Jakarta Sans (Clean Modern Sans)

---

## 💎 7 Implemented Key Sections

1. **Ambient Background (ThreeUI / 21st.dev style)**:
   - Dynamic HTML5 canvas shader rendering drifting organic rose & amber light orbs with micro-mesh grain.
2. **Sticky Glassmorphism Header**:
   - `backdrop-blur-md bg-[#FCF9F2]/80 border-b border-rose-100/60`
   - Active spring burgundy indicator line with layout animations.
   - Mobile responsive drawer with accessible focus controls.
3. **Hero Section**:
   - Left Column: Shimmer badge (`★ THOUGHTFULLY CURATED GIFTS`), staggered headline, dual spring physics CTA buttons, live stats.
   - Right Column: 3D tilt & Spotlight card for *"Artisan Leather Keepsake Journal"* with `+12 Score` pill and 21st.dev `BorderBeam` effect.
4. **Interactive Occasion Pill Cloud ("What are you celebrating?")**:
   - DaisyUI badge tags with icons, hover spring scaling, border illumination, and active state tracking.
5. **Relationship Grid ("Who are you gifting today?")**:
   - 6 interactive spotlight cards with cursor-following radial gradient lighting and sliding arrows.
6. **Bespoke Gifting Flow & Stepper ("Something one-of-a-kind?")**:
   - 3-step interactive roadmap connected by an animated SVG timeline dashed line.
7. **Multi-step Gift Finder Form ("Find the Perfect Gift")**:
   - Interactive selectors for Relationship, Gender, Budget, and Occasion.
   - Dynamic pulse submit button with loading state transition and recommendation reveal.

